## 🎯 Quick Deployment (5 minutes)

### 1. Create GitHub Repository
```bash
# Go to https://github.com/new
# Create: "torrent-streamer-website"
# Then run:
git remote add origin https://github.com/YOUR-USERNAME/torrent-streamer-website.git
git branch -M main
git push -u origin main
```

### 2. Connect to Netlify
- Go to https://app.netlify.com/signup
- Sign up with GitHub
- Click "New site from Git"
- Select your repository
- Click "Deploy site"

### 3. Get Your Live URL
- Netlify automatically builds and deploys
- Your site goes live at: `https://random-name.netlify.app`
- Add custom domain anytime in Site Settings
